# DroidDock for macOS

DroidDock creates and runs Android virtual devices on your Mac, so you can try and test Android apps without a phone. It shows each device's screen in its own window and has controls for location, sensors, battery, network, screen recording and logs.

**DroidDock is free.** No subscription, no licence key, no ads and nothing to buy inside the app.

## Download

Download the latest `DroidDock-*.dmg` from the [Releases page](https://github.com/ErIMRANALAM/DroidDock-Releases/releases/latest), open it and drag **DroidDock** to **Applications**.

- Works on Apple silicon and Intel Macs running **macOS 15 or later** (one universal app).
- Needs **Android Studio** installed and opened once, so the Android SDK exists. DroidDock uses that SDK; it does not contain Android, the emulator or any system image.

See [INSTALL.md](INSTALL.md) for set-up and first steps.

## Updates

DroidDock updates itself. It checks this repository's `appcast.xml` once a day (or choose **DroidDock › Check for Updates…**), shows a banner when a new version is available, and installs it when you choose. Every update is signed and verified before it installs. You can turn automatic checks off in **Settings**.

## Privacy

DroidDock has no accounts, no analytics and sends no personal data. The only thing it requests online is the list of versions from this repository, about once a day. Your devices, recordings and logs stay on your Mac.

## Support

Use **Help › Report a Problem…** in the app, which opens an email with your diagnostics ready to send, or write to hello@imranalam.in.
